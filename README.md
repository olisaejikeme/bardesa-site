# bardesa.com

A static site: plain HTML, no build step. Hosted on Cloudflare Pages.

- `index.html`: the page
- `404.html`: shown for unknown links
- `favicon.svg`: the tab icon
- `_headers`: security headers Cloudflare Pages applies to every response

To change the text, edit `index.html` and push. Cloudflare redeploys in under a minute.
